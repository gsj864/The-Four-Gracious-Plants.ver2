# 사군자 기질검사

매화·난초·국화·대나무 네 가지 유형 중 자신의 기질을 찾아보는 웹 기반 성향 검사입니다.

## 실행 방법

1. 프로젝트 폴더를 연 뒤 `index.html`을 브라우저에서 엽니다.
2. 또는 로컬 서버를 사용합니다.
   ```bash
   npx serve .
   ```
   이후 브라우저에서 표시되는 주소(예: http://localhost:3000)로 접속합니다.

## 사용 방법

1. **메인 페이지** (`index.html`)에서 검사 설명을 읽고 **검사 시작**을 누릅니다.
2. **검사 페이지**에서 각 문항마다 4개 단어 중  
   - 가장 자신에 가까운 것에 **○** (첫 번째 클릭)  
   - 그다음 가까운 것에 **△** (두 번째 클릭)  
   선택합니다. 같은 단어를 다시 누르면 선택이 해제됩니다.
3. 20문항을 모두 답한 뒤 **결과 보기**를 누르면 유형(매화 / 난초 / 국화 / 대나무) 결과를 볼 수 있습니다.
4. **다시 검사하기**를 누르면 확인 후 메인 페이지로 돌아갑니다.

## 프로젝트 구조

| 파일 | 설명 |
|------|------|
| `index.html` | 메인(시작) 페이지 |
| `test.html` | 검사 문항 + 결과 페이지 |
| `style.css` | 공통 스타일 (메인, 검사, 결과, 다크 모드) |
| `app.js` | 검사 로직, 문항 데이터, 점수 계산, 결과 표시 |
| `theme.js` | 다크 모드 토글 및 설정 저장 |

## 기능

- **진행도 저장**: 새로 고침해도 진행 상황 유지 (localStorage)
- **다크 모드**: 우측 상단 버튼(🌙/☀)으로 전환, 선택값 저장
- **반응형**: 모바일·데스크톱에서 사용 가능

## 기술

- HTML, CSS, JavaScript (Vanilla)
- 외부 라이브러리 없음
